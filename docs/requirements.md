## 1. Введение

### 1.1 Назначение

Настоящий документ описывает функциональные и нефункциональные требования к кроссплатформенному приложению криптографических методов и алгоритмов, реализованному на C++ с использованием фреймворка Qt6.

### 1.2 Область применения

Приложение предназначено для:
- демонстрации криптографических методов (Шифр Виженера, md5)
- реализации численных методов (метод секущих)
- работы с графами (проверка цикла)
- изучения паттернов проектирования (Singleton)
- обучения принципам клиент-серверной архитектуры

### 1.3 Определения и сокращения

| Термин | Определение |
|--------|-------------|
| **GUI** | Graphical User Interface — графический интерфейс пользователя |
| **Singleton** | Порождающий паттерн проектирования, гарантирующий единственный экземпляр класса |
| **md5** | Криптографическая хэш-функция, возвращающая 128-битный хэш |
| **MOC** | Meta-Object Compiler — компилятор мета-объектов Qt |
| **CMake** | Кроссплатформенная система сборки |
| **Ninja** | Высокоскоростная система сборки |

## 2. Общее описание

### 2.1 Перспектива продукта

Приложение является **самостоятельным** desktop-приложением, не требующим подключения к внешней базе данных. **Серверная часть** реализована в виде **заглушки** (`ServerStub`), имитирующей обработку запросов авторизации.

|----|---------|-----------|

| F-03 | Вычисление md5-хэша | Высокий |
| F-04 | Решение уравнения методом секущих | Высокий |
| F-05 | Проверка цикла графа | Высокий |
| F-06 | Ведение истории операций | Средний |

### 2.3 Классы пользователей

| Класс | Описание |
|-------|----------|
| **Пользователь** | Основной пользователь, работающий с модулями |
| **Администратор** | Пользователь с расширенными правами (заложено в архитектуру) |

### 2.4 Ограничения

- **ОС:** Windows 10/11, Linux, macOS
- **Язык:** C++17

## 3. Функциональные требования

### 3.1 Авторизация (F-01)

| Поле | Значение |
|------|----------|
| **ID** | FR-01 |
| **Название** | Вход в систему |
| **Актеры** | Пользователь, Сервер (заглушка) |
| **Предусловие** | Приложение запущено |
| **Основной поток** | 1. Пользователь вводит логин/пароль<br>2. Нажимает «Войти»<br>3. Система формирует запрос `auth&login&password`<br>4. Сервер возвращает `auth&ok`<br>5. Открывается главное меню |
| **Альтернативный поток** | Сервер возвращает `auth&fail` → сообщение об ошибке |
| **Валидация** | Логин и пароль не должны быть пустыми |
| **Тестовые данные** | `admin` / `12345` |

### 3.2 Шифр Виженера (F-02)

| Поле | Значение |
|------|----------|
| **ID** | FR-02 |
| **Название** | Шифрование и дешифрование текста |
| **Актеры** | Пользователь |
| **Основной поток** | 1. Ввод текста (латиница)<br>2. Ввод ключа (латиница)<br>3. Нажатие «Зашифровать» или «Расшифровать»<br>4. Отображение результата |
| **Валидация** | Только символы `[a-zA-Z ]` |
| **Тестовые данные** | `HELLO WORLD` + `KEY` → `RIJVS UVYJN` |

### 3.3 md5-хэш (F-03)

| Поле | Значение |
|------|----------|
| **ID** | FR-03 |
| **Название** | Вычисление md5-хэша |
| **Основной поток** | 1. Ввод текста<br>2. Нажатие «Хэшировать»<br>3. Отображение 32-символьного хэша |
| **Дополнительно** | Копирование хэша в буфер; сравнение с эталоном |
| **Тестовые данные** | `hello` → `5d41402abc4b2a76b9719d911017c592` |

### 3.4 Метод секущих (F-04)

| Поле | Значение |
|------|----------|
| **ID** | FR-04 |

| **Тестовые данные** | `1 3 4 2 1` → ✅ ЦИКЛ |

## 4. Нефункциональные требования

### 4.1 Производительность

- **Время запуска:** ≤ 2 секунд
- **Время обработки запроса:** ≤ 100 мс
- **Время генерации md5:** ≤ 10 мс

### 4.2 Надёжность

- **Обработка ошибок:** все исключительные ситуации сопровождаются `QMessageBox`
- **Валидация ввода:** проверка всех полей перед обработкой

### 4.3 Удобство использования

- **Язык интерфейса:** русский
- **Эмодзи:** для наглядности (🔐, 🔑, 📐, 🔀, 📊)
- **Подсказки:** placeholder-текст в полях ввода
- **Валидация в реальном времени:** `QRegularExpressionValidator`

### 4.4 Совместимость

- **ОС:** Windows 10/11 (основная), Linux, macOS
- **Qt:** 6.11.2+
- **Компиляторы:** GCC 13+, MSVC 2022+

### 4.5 Сопровождаемость

- **Стиль кода:** единообразный, с комментариями
- **Структура:** модульная (отдельные классы для каждой функции)
- **Тесты:** 5 unit-тестов (Qt Test), покрытие ≥ 80%
- **Git:** осмысленные коммиты, .gitignore

### 4.6 Безопасность

- **Пароль:** скрывается (`QLineEdit::Password`)
- **md5:** криптографический хэш (не хранит пароль в открытом виде)
- **Заглушка сервера:** изолирована, не подключается к БД

## 5. Архитектура

### 5.1 Общая схема

**Клиент-серверная архитектура** (сервер — заглушка) с паттерном **Singleton**.

LoginWindow → Client (Singleton) ← UserWindow → 4 модуля + HistoryWindow
↑
ServerStub


### 5.2 Основные классы

| Класс | Роль |
|-------|------|
| `Client` | Singleton, хранит сессию, историю |
| `ServerStub` | Заглушка сервера |
| `LoginWindow` | Авторизация |
| `UserWindow` | Главное меню |
| `HistoryWindow` | История операций |
| `VigenereWindow`, `MD5Window`, `SecantWindow`, `GraphWindow` | Модули |
| `VigenereCipher`, `MD5`, `SecantMethod`, `GraphCycle` | Алгоритмы |

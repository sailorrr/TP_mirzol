## 2. Уровни тестирования

### 2.1 Модульное (Unit) тестирование

**Цель:** проверить корректность работы отдельных функций и классов.

**Инструменты:** Qt Test Framework (`QTest`, `QCOMPARE`, `QVERIFY`).

**Объекты тестирования:**

| Модуль | Тестовый класс | Покрытие |
|--------|---------------|----------|
| `VigenereCipher` | `TestVigenere` | Шифрование, дешифрование, roundtrip, пустой ключ |
| `MD5` | `TestMD5` | Хэш от различных строк |
| `SecantMethod` | `TestSecant` | Корень уравнения, точность |
| `GraphCycle` | `TestGraph` | Цикл, не цикл, отсутствие ребра |
| `ServerStub` | `TestServer` | Авторизация ok/fail, пустой запрос |

**Критерий успеха:** `100% tests passed, 0 tests failed out of 5`.

**Расположение:** `tests/` в корне проекта.

### 2.2 Интеграционное тестирование

**Цель:** проверить взаимодействие модулей.

**Сценарии:**
- `LoginWindow` → `Client::instance()` → `UserWindow` (передача пользователя)
- `UserWindow` → 4 окна модулей (создание и отображение)
- `UserWindow` → `HistoryWindow` → `Client::getHistory()` (получение лога)

**Метод:** ручное тестирование по сценариям.

### 2.3 Системное тестирование

**Цель:** проверить приложение как единое целое.

**Инструменты:** ручное тестирование, чек-лист.

**Сценарии:**
- Запуск приложения → авторизация → работа со всеми модулями → выход
- Проверка GUI на разных разрешениях экрана

### 2.4 Приёмочное тестирование

**Цель:** подтвердить соответствие требованиям.

**Метод:** демонстрация преподавателю.

## 3. Виды тестирования

### 3.1 Функциональное

| Функция | Метод | Ожидаемый результат |
|---------|-------|---------------------|
| Авторизация | Ввод `admin`/`12345` | Открытие меню |
| Ошибочный вход | Ввод `wrong`/`123` | Сообщение об ошибке |
| Шифрование | `HELLO WORLD` + `KEY` | `RIJVS UVYJN` |
| md5 | `hello` | `5d41402abc4b2a76b9719d911017c592` |
| Секущие | x₀=2, x₁=3 | x ≈ 2.0945514815 |
| Цикл | `1 3 4 2 1` | ✅ ЦИКЛ |
| Не цикл | `1 2 3` | ❌ НЕ ЦИКЛ |

### 3.2 UI/UX тестирование

- Проверка отображения всех окон
- Корректность эмодзи (🔐, 🔑, 📐, 🔀, 📊)
- Работа кнопок и полей ввода
- Валидация `QRegularExpressionValidator`

### 3.3 Тестирование валидации

| Поле | Проверка |
|------|----------|
| Логин/пароль | Пустые поля → ошибка |
| Виженер текст | Кириллица → ошибка |
| Виженер ключ | Не латиница → ошибка |
| x₀, x₁ | x₀ = x₁ → ошибка |
| ε | ε ≤ 0 → ошибка |
| Граф | Матрица с 0/1 → ок, иначе ошибка |
| Граф путь | Вершины 1-5, не пусто |

### 3.4 Регрессионное тестирование

**При каждом изменении кода:**
1. Пересобрать проект (`ninja`)
2. Запустить `ctest --output-on-failure`
3. Убедиться: `100% tests passed`

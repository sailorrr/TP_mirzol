## 📋 Описание проекта

Кроссплатформенное приложение на **Qt6 / C++** с графическим интерфейсом, реализующее четыре модуля:

| № | Модуль | Алгоритм |
|---|--------|----------|
| 1 | **Шифр Виженера** | Шифрование/дешифрование текста ключом |
| 2 | **md5-хэш** | Хэширование и сравнение с эталоном |
| 3 | **Метод секущих** | Численное решение уравнения f(x) = 0 |
| 4 | **Проверка цикла графа** | Проверка, что последовательность вершин образует цикл |

**Дополнительно:**
- Авторизация через заглушку сервера
- Singleton-паттерн для клиента (`Client`)
- История операций в виде таблицы (`QTableWidget`)
- 5 модульных тестов (`Qt Test`)

## 🚀 Сборка

### Требования

- Qt 6.11.2 (или выше)
- CMake 3.16+
- Компилятор: GCC (MinGW/w64devkit) или MSVC

### Команды

```bash
# Клонировать репозиторий
git clone https://github.com/sailorrr/TP_mirzol.git
cd TP_mirzol

# Создать папку сборки
mkdir build
cd build

# Настроить CMake
cmake .. -G Ninja \
  -DCMAKE_PREFIX_PATH=C:/Qt/6.11.2/mingw_64 \
  -DCMAKE_C_COMPILER=C:/w64devkit/bin/gcc.exe \
  -DCMAKE_CXX_COMPILER=C:/w64devkit/bin/g++.exe

# Собрать
ninja

# Запустить приложение
./lab-crypto.exe
